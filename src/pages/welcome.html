ChatStamp

Your chats now have dates

ChatStamp shows when each ChatGPT and Claude chat started, so you can find a conversation by when it happened. Reload any open chat tabs to see it.

What you get

Dates in the sidebarOn all your chats, including ones from before you installed ChatStamp.
A time on every messageThe date and time appear above each message inside a chat.
Search across both sitesClick the toolbar icon to find a chat by title, site or date.
Print any chat as PDFUse the button beside Share in a chat, or the PDF button in the popup.

A date starting with ~ is an estimate: the first time ChatStamp saw that chat, not the moment it was created. Hover any date for the full date and time.

Your data stays here

Dates are stored only in this browser. ChatStamp has no server, no account and no analytics. It keeps each chat's site, ID, title and dates, and it never stores the text of your messages. Message text is only used when you print a chat as PDF, and it stays in that tab.
